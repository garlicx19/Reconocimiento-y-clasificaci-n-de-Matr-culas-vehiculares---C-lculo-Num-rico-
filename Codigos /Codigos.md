# Códigos

Scripts del proyecto. Cada uno cubre una etapa del trabajo con las matrículas.

## Contenido

| Script | Descripción |
|---|---|
| [Generar Datasets.py](Generar%20Datasets.py) | Genera los datasets a partir de los datos obtenidos |
| [Identificar_tipos.py](Identificar_tipos.py) | Identifica el tipo de matrícula |
| [extractor_de_texto.py](extractor_de_texto.py) | Extrae el texto de las imágenes de matrículas |

## Generar Datasets.py

**Qué hace:** *Genera imagenes de ejemplo de matriculas aleatorias que tienen el formato de las paraguayas, tanto del modelo antiguo como el del mercosur*


## extractor_de_texto.py

**Qué hace:** *Se entrena con las imagenes de prueba y luego identifica el texto de las matriculas obtenidas*
**Que devuelve**  *Devuelve un archivo .csv con el texto obtenido a partir de las imagenes*

## Identificar_tipos.py

**Qué hace:** *Toma el archivo .csv que se obtuvo del codigo anterior y genera otro con el tipo de chapa (antigua / Mercosur) y la categoria (auto / moto)*
