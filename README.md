# Reconocimiento y clasificación de Matrículas vehiculares - Cálculo Numérico
Trabajo Práctico de calculo numérico, sobre un algoritmo de reconocimiento de matrículas


Integrantes: 
-Adrian Colman
-Matias Pacuá



Objetivo: Diseñar y entrenar una algoritmo que reconozca, clasifique y digitalice a partir de imágenes números de matrícula vehiculares.

Descripción del problema: El registro de vehículos en la entrada y salida del Parana Country Club es poco eficiente y eficaz para identificar a las personas que frecuentan la zona, por lo que con un algoritmo de Machine Learning es posible llevar uno de manera eficaz y exacta.

Método Utilizado: 

- Reconocimiento de imágenes con mapas

Instrucciones para ejecutar el código:
- Ejecutar el código "Generar Datasets.py" que crea la carpeta de "dataset" y el archivo Dataset-matriculas.csv con distintas matriculas separadas en su respectiva categoría (Mercosur, Antigua, Automovil, Moto).
