# Reconocimiento-y-clasificacion-de-Matriculas-vehiculares---Calculo-Numerico-
Trabajo Práctico de calculo numérico, sobre un algortimo de reconocimiento de matrículas


Integrantes: 
-Adrian Colman
-Matias Pacuá

Objetivo: Diseñar y entrenar una algoritmo que reconozca, clasifique y digitalize a partir de imágenes numeros de matrícula vehiculares.

Descripción del problema: El registro de vehículos en la entrada y salida del Parana Country Club es poco eficiente y eficaz para identificar a las personas que frecuentan la zona, por lo que con un algoritmo de Machine Learning es posible llevar uno de manera eficaz y exacta.

Método Utilizado: 

- Reconocimiento de imágenes con mapas
